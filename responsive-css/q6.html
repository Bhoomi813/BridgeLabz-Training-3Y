Responsive CSS Cheat Sheet

Filters

filter: grayscale(100%);

Applies a grayscale effect to an image.

Media Queries

@media (max-width: 700px)

Applies styles when the screen is small.

Responsive Design

width: 100%;

Allows an element to fit its available container.

Typography

font-size: clamp(1rem, 2vw, 1.5rem);

Scales text size within set limits.

Flexbox

display: flex;

Arranges items in a flexible row or column.

CSS Grid

display: grid;

Arranges elements into rows and columns.
